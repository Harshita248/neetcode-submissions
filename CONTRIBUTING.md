# Contributing to NeetCode Solutions

Thank you for your interest in contributing to this repository!

## Purpose of this Repository

This repository contains accepted solutions for NeetCode problems. Solutions are automatically synced from NeetCode submissions and organized by topic and problem.

## How You Can Contribute

Contributions are welcome in the following areas:

* Improving documentation
* Fixing typos and formatting issues
* Enhancing README content
* Suggesting repository structure improvements
* Reporting issues

## Before Contributing

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes following the existing structure.
4. Test and verify your changes.
5. Submit a Pull Request with a clear description.

## Repository Structure

```text
<topic-folder>/
└── <problem-id>/
    ├── submission-0.ext
    ├── submission-1.ext
    └── ...
```

Each problem is stored within its topic folder, and multiple submissions may exist for the same problem.

## Pull Request Guidelines

* Keep changes focused and minimal.
* Use clear commit messages.
* Update documentation when necessary.
* Ensure changes do not break the existing repository structure.

## Issue Guidelines

When creating an issue, please include:

* A clear title
* A detailed description
* Steps to reproduce (if applicable)
* Suggested improvements or solutions

## ECSoC Contributors

Please claim an issue before starting work and wait for assignment from the maintainers before submitting a Pull Request.

## Code of Conduct

Please be respectful and constructive in all interactions. Maintain a welcoming environment for everyone.

## Questions

If you have any questions, feel free to open an issue for discussion.

Thank you for contributing!
