## 📌 About This Repo

This repository is a live archive of my DSA solutions — auto-pushed directly from [NeetCode.io](https://neetcode.io) every time I submit an accepted solution.

- ⚡ **Auto-synced** via NeetCode's GitHub Integration — no manual copy-paste
- 🔗 **Connected** from `neetcode.io/profile/github` → this repo
- 📚 **Covers** NeetCode 150 / Blind 75 style problems across core DSA topics
- 🗂️ **Organized** by topic folder → problem ID → submission file(s)

---

## ⚙️ How GitHub Sync Works

1. **Connect** your GitHub account at [neetcode.io/profile/github](https://neetcode.io/profile/github)
2. **Auto-commit** — every accepted submission triggers a push to this repo automatically
3. **Bulk Sync** — push all past solutions at once from the GitHub settings page
4. **Manual sync** — per-problem control from the submission history panel on any problem page

---

## 🗂️ Repository Structure

Solutions are organized by topic, then problem slug. Multiple submissions per problem are versioned sequentially.

```
<topic-folder>/
  <problem-id>/
    submission-0.<ext>   ← first accepted
    submission-1.<ext>   ← revised / retry
    ...
```

**Real examples:**
```
Data Structures & Algorithms/two-integer-sum/submission-0.py
Data Structures & Algorithms/binary-search/submission-0.ts
Python For Beginners/python-hello-world/submission-0.py
```

## 🔧 Sync Settings

All sync preferences are managed at [neetcode.io/profile/github](https://neetcode.io/profile/github):

| Setting | Description |
|---|---|
| **Auto-commit toggle** | Enable / disable automatic commits on each submission |
| **Status filter** | Sync accepted solutions only, or all submissions |
| **Rename repository** | Rename this repo or start fresh with a new one |
| **Bulk Sync** | Push all past solutions at once *(rate-limited)* |

## 🤝 Contributing

This repo welcomes DSA solutions in any supported language!

**Quick contribute flow:**

1. **Fork** this repository
2. **Add your solution** under the correct topic folder following the existing structure:
   ```
   Data Structures & Algorithms/<problem-id>/submission-0.<ext>
   ```
3. **Open a PR** with the problem name + language in the title
   > e.g. `Add: two-integer-sum — Python`

For full guidelines, see [CONTRIBUTING.md](./CONTRIBUTING.md).
