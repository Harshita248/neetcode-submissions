A collection of coding interview solutions synced automatically from **NeetCode.io**. Solutions are organized by topic and problem, making it easier to track progress and revisit solved problems.

---

## 📌 About

NeetCode.io is a coding interview preparation platform featuring curated problems, video explanations, and an in-browser editor. This repository stores solutions submitted through the GitHub Sync feature.

---

## 🚀 Features

* Automatic synchronization from NeetCode.io
* Organized topic-wise structure
* Supports multiple programming languages
* Tracks submission history
* Easy revision and progress monitoring

---

## 📂 Repository Structure

```text
<topic-folder>/
  <problem-id>/
    submission-0.<ext>
    submission-1.<ext>
    ...
```

### Example

```text
Data Structures & Algorithms/
 ├── two-integer-sum/
 │    └── submission-0.py
 ├── binary-search/
 │    └── submission-0.cpp
```

## 🔄 GitHub Sync Workflow

1. Connect your GitHub account on **NeetCode.io**.
2. Submit solutions on NeetCode.
3. Solutions are automatically committed to this repository.
4. Access and review your submissions anytime.
